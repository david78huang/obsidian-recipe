# 🏠 智慧家食谱管理

欢迎来到智慧家的食谱管理系统！

## 📁 目录结构

```
📅 每日记录/      - 每天实际吃了什么
📊 每周食谱/      - 每周计划食谱
📈 营养分析/      - 每月营养报告
🍳 菜谱库/        - 收藏的菜谱
📋 购物清单/      - 要买的东西
Templates/        - 笔记模板
```

## 🚀 快速开始

### 记录今天的饮食
1. 打开 `📅 每日记录/`
2. 新建笔记（用模板）
3. 填写今天实际吃了什么

### 查看本周食谱
1. 打开 `📊 每周食谱/`
2. 查看当前周计划

### 添加新菜谱
1. 打开 `🍳 菜谱库/`
2. 新建笔记记录菜谱

## 💡 使用技巧

- **语音记录**：直接发语音给我，我帮你记录
- **拍照识别**：拍冰箱照片，我推荐菜谱
- **自动生成**：每周日晚自动生成下周食谱
